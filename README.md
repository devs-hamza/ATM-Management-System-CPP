# ATM Management System

A beginner-level **ATM simulation program written in C++**. This project was created to practice fundamental C++ concepts such as functions, conditional statements, user input, and basic program structure.

## Features

- Deposit money
- Check account balance
- Withdraw money
- Insufficient-balance checking
- Invalid-option handling
- Exit option
- Menu-based interaction

## Concepts Practiced

- C++ input/output
- Variables and data types
- `if / else if / else`
- Functions
- Header files
- Basic program organization
- User input and validation

## Project Structure

```text
ATM-Management-System-CPP/
├── ATM.cpp
├── functions.h
├── functions.cpp
├── README.md
└── .gitignore
```

## How It Works

The program displays an ATM menu, accepts the user's selected operation, and then performs the corresponding action using C++ functions and conditional statements.
